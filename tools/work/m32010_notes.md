## 五、存疑与疑似笔误清单（均照录不改）

1. **p2 题(7) C 选项**印作 `$\dfrac{1}{2}-e^{1}$`（指数无负号，3–4 倍放大确认）；p6 解析算得 `$\dfrac{1}{2}-e^{-1}$`，可见 C 选项指数应为 −1。原卷笔误，照录。
2. **p2 题(13) 题干**条件后印作 `|A^{-1}+B|=2,，则`（半角逗号后又跟全角逗号，双逗号，3 倍放大确认）。照录。
3. **p1 题(6) 题干**`A^{2}+A=0` 与"若"之间无标点（3 倍放大确认），照录。
4. **p5 解析卷头**选择题说明行印作"二、选择题"，与试卷 p1"一、选择题"不一致。照录。

7. **"带入/代入"混用**：p5 题(2) 详解两处"带入微分方程"、p7 题(11) 详解"带入初始条件"为"带入"；p6 题(9) 详解"代入上式"为"代入"。均按原页照录。
