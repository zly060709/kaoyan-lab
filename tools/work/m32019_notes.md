## 五、原卷疑似笔误/排版问题清单（一律照录，未改正）

1. p1 第(6)题题干："E 是阶单位矩阵"——疑脱"3"字（应为"E 是 3 阶单位矩阵"）。3 倍裁剪（c01）确认原卷如此。
2. p5 第(4)题【解析】："lim_{x→∞}|u_n|/|nu_n|=0"——极限变量排作 x→∞，疑应为 n→∞。3 倍裁剪（c02）确认。
3. p5 第(4)题【解析】："可知 ∑u_n 也对决收敛"——"对决"疑为"绝对"。3 倍裁剪（c02）确认。
4. p7 第(13)题【解析】："因为 Ax=b 由无穷多解"——"由"疑为"有"。3 倍裁剪（c04）确认。
5. p11 第(22)题(III)："所以 P(X≤1, Z≤1) ≠ P(X≤1)P(Z≤−1)"——左侧"Z≤1"疑应为"Z≤−1"。3 倍裁剪（c08）确认。
6. p4 第(23)题题干："X₁,X₂,⋯,X_n 是来自总体 X 简单随机样本"——疑脱"的"字（应为"来自总体 X 的简单随机样本"）。
7. p10 第(21)题(II)小问"求可逆矩阵 P,使得 P⁻¹AP=B"——句末无标点、逗号为半角，照原样保留。
