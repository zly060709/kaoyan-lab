# 考研全栈学习平台（kaoyan-lab）

考研政治 / 数学一 / 英语一 / 408 计算机 真题「逐题精讲」统一学习平台。
纯静态：无后端、无登录、无构建步骤；学习数据全部保存在浏览器本地（IndexedDB/localStorage）。
